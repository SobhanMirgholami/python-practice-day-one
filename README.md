# Python Fundamentals — Loop Practice Projects

A collection of four beginner-friendly Python projects developed as part of my programming learning journey.

These exercises focus on strengthening my understanding of Python fundamentals, including loops, conditional statements, functions, user input handling, and basic problem-solving.

## Projects

### 1. Even & Odd Numbers
**File:** `even_odd.py`

A simple program that displays even and odd numbers between 1 and 100.

**Concepts practiced:**
- `for` loops
- `range()` function
- Step values
- Formatted strings (f-strings)

### 2. Multiplication Table
**File:** `multiplication_table.py`

Generates a multiplication table from 1 to 10 for a number entered by the user.

**Concepts practiced:**
- User input with `input()`
- Type conversion
- Loops and arithmetic operations
- Formatted output

### 3. Number Guessing Game
**File:** `guessing_game.py`

An interactive guessing game where the computer randomly selects a number between 1 and 20. The player receives hints until the correct number is guessed.

**Features:**
- Random number generation
- High/low guessing hints
- Attempt counter
- Invalid input handling

**Concepts practiced:** `while` loops, `if/elif/else`, `break`, `continue`, `random`, and exception handling.

### 4. ATM Simulator
**File:** `atm_simulator.py`

A console-based ATM simulation that allows users to perform basic banking operations.

**Features:**
- Check account balance
- Deposit money
- Withdraw money
- Validate transaction amounts
- Prevent withdrawals exceeding the available balance
- Exit through an interactive menu

**Concepts practiced:** Functions, return values, conditional logic, loops, and error handling.

*This project is an educational simulation and does not connect to real banking systems.*

## How to Run

1. Install Python 3.
2. Clone the repository:

   ```bash
   git clone https://github.com/YOUR_USERNAME/python-fundamentals.git
   ```

3. Navigate to the project directory:

   ```bash
   cd python-fundamentals/lesson02
   ```

4. Run any project, for example:

   ```bash
   python guessing_game.py
   ```

Replace `YOUR_USERNAME` with your GitHub username.
